### Curriculum Modules

The curriculum is designed to achieve competency in four subject matters with an emphasis on testing, security, and project management.

#### Part I: Linux Administration (4 Weeks)
* **Goal:** Develop competency for administrative activities rather than end-user task.
* **Core Topics:**
    * **Terminal & Tools:** Shell commands, environment variables, and shell automation.
    * **File Management:** Managing permissions, archiving (tar, cpio), and recursive management.
    * **System Operations:** Process management (creating/killing processes), boot sequences (BIOS/EFI to ready state), and drive partitioning.
    * **Scripting:** Basic scripting, pipes, streams, and bash scripts.


#### Part II: Networking Fundamentals (2 Weeks)
* **Infrastructure:** Coverage of LANs, WANs, VPNs, firewalls, and wireless bridging.
* **Hardware & Media:** Hubs, switches, routers, copper vs. fiber media, and noise control.
* **Protocols:** Deep dive into the OSI model, TCP/IP suite, IPv4/IPv6, DNS, and DHCP.
* **Security:** Vulnerabilities, authentication, encryption, and intrusion detection/prevention.


#### Part III: Web Fundamentals (2 Weeks)
* **Goal:** Establish comfort with code editors and markup for wireframing and mockups, rather than full mastery.
* **Core Topics:**
    * **HTML/CSS:** HTML5 features, forms, grid/fluid layouts, animations, and transitions.
    * **Scripting:** Core elements like variables, flow control, and functions for recycling code.

#### Part IV: JavaScript Frameworks (4 Weeks)
* **Goal:** Understand modern frameworks using the MEAN stack (MongoDB, Express, Angular, Node).
* **Benefits:** Uses a single language (JavaScript) for every level of the application.
* **Core Topics:** MVC architecture, REST APIs, Single-Page Application (SPA) development, and React.js.


#### Part V: Python or Second Stack (4 Weeks)
* **Goal:** Establish basic competency in Python due to its adaptability in cloud infrastructure and data science.
* *Note: This slot may also be used for Java, C#/.Net, or Swift depending on employer discretion.*
* **Core Topics:**
    * **Basics:** Syntax, mutable vs. immutable types, and assignment semantics.
    * **Advanced:** Crawling/scraping, OOP in Python, MVC frameworks, and Test-driven Development.

### Training Schedule

The program follows a sequential flow combining Instructor-Led Training (ILT), Online Training (OLT), and Labs.

| Weeks | Focus | Key Activities |
| :--- | :--- | :--- |
| **1–2** | Linux | Practice skills and labs (Solo/Group) |
| **3–4** | Linux | Project (20–40 hours effort) and Linux+ Exam |
| **5–6** | Networking | Lectures, discussions, and demos |
| **7–8** | Web Fundamentals | Web app project (20–40 hours) or belt exam |
| **9–11** | JS Frameworks | Labs involving Node, Angular, or React |
| **12** | JS Frameworks | Project (40 hours effort) and/or belt exam |
| **13–15** | Python/Other | Learning syntax, libraries, and scraping |
